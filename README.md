# fullstack_assingment
### Features
* Signip and Signin page
* On successfull signin issue a JWT token
* user to log in from multiple devices/clients using the same credentials.
* User account block after 3 consecutive failed login attemps.
* Password expire after 10days.
* Prevents users from reusing the last 3 passwords when changing passwords.
* Use Redux to manage authenticated state such as logged-in user data, token, etc.
